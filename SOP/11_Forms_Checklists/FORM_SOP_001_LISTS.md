# FORM_SOP_001: Operational Forms, Lists & Checklists
## Care Diagnostics ERP Standard Operating Procedure

---

## 1. Daily Opening Checklist (Front Desk & IT)
- [ ] Server rack power and cooling checked.
- [ ] Synology DSM Container Manager shows all containers (web, api, db, orthanc) are `running`.
- [ ] Network ping to LAN IP `192.168.1.137` is successful.
- [ ] Barcode printers and ticket printers stocked with thermal rolls.
- [ ] Kiosk self-registration terminals turned on and verified online.
- [ ] Card payment POS machine online and test transaction passes.

---

## 2. Daily Closing Checklist (Cashier & IT)
- [ ] Open the **My Daily Summary** page in the ERP.
- [ ] Perform a physical cash count and reconcile against expected total in ERP drawer.
- [ ] Verify card receipts and UPI transaction logs match gateway settlement totals.
- [ ] Submit Day Close in the ERP.
- [ ] Verify database automatic backup cron script has completed without errors.
- [ ] Lock the cashier drawer and deposit cash into drop box.
